# 바다낚시·차박 지도

유튜브 낚시·차박 채널의 영상 제목·설명·댓글에서 장소를 뽑아 지도로 만듭니다.
바다낚시지수(국립해양조사원)는 매일 새로 받아 근처 장소에 붙입니다.

## 흐름
1. `collect.py` 채널별 영상과 영상당 댓글 상위 200개 수집 (YouTube API)
2. `extract.py` 영상마다 장소·어종·편의시설·뷰·주의사항·후기 추출 (Claude)
3. `fishing_index.py` 바다낚시지수 받기 (공공데이터포털)
4. `build.py` 카카오로 위치 확인, 근처 공중화장실 검색, 15km 안의 지수 지점 연결 → `site/index.html`, `output/바다낚시_차박_장소.xlsx`

채널 목록은 `channels.json`에서 바꿀 수 있습니다.

## 실행 주기
- 매일 오전 5:40: 바다낚시지수만 받아 지도 갱신
- 매달 1일 오전 10:20: 새 영상까지 전체 갱신
- 수동: Actions → 바다낚시·차박 지도 → Run workflow (full=1 전체, 0 지수만)
